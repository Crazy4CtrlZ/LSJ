# Policy Corpus — LSJ, Inc. (Synthetic)

Sixteen fictional company policy documents authored (with AI assistance) for the Quantic MSAIE AI Engineering project. Every document is synthetic; no real company, employees, or personal data.

The corpus uses all four source formats named in the rubric ("about 5-20 short markdown, HTML, PDF, or TXT files"): **6 Markdown, 2 PDF, 4 HTML, 4 TXT**. Markdown carries the highest-traffic policies because it is the most reliable format for LLM ingestion and heading-aware chunking; the PDF/HTML/TXT documents exercise the rubric's multi-format parsing requirement ("handling at least two supported source formats"). Each policy exists in exactly one canonical format so the index never contains duplicate chunks.

## Design notes (for RAG ingestion)

- Every document carries a stable `doc_id` plus title, category, version, and last-updated date — YAML front matter in MD, `<meta>` tags in HTML, header lines in TXT and PDF — the metadata needed for citations.
- All documents use numbered sections (e.g., "3.1 Notice requirements") so `get_policy_section(doc_id, section)` can address them and citations can point at document + section.
- Documents deliberately cross-reference each other (e.g., POL-002 §5 → POL-007 §6; POL-001 §3.2 → POL-010 §4) so multi-document retrieval questions are natural.
- Key facts wired in for the demo tasks:
  - **PTO demo:** 3-day request needs 10 business days' notice (POL-001 §3.1) + manager approval (POL-001 §3.2 / POL-010 §4); insufficient balance path in POL-001 §3.3.
  - **Remote-work demo:** international remote work capped at 20 business days per rolling 12 months (POL-002 §5.1); six weeks exceeds it → Legal & Tax exception review (POL-002 §5.4); security conditions in POL-007 §6; approval matrix row in POL-010 §4.
  - **Guardrail anchors:** what automation may/may not do (POL-015 §6); sensitive-case human-only routing (POL-005 §4.2).
- Editable Markdown sources for the non-MD documents (POL-012 through POL-016 conversions) live in `corpus_src/` with `convert_corpus.py`; POL-007/POL-008 are generated by `build_pdfs.py`; POL-009/POL-010/POL-011 are edited directly.

Rendered size ≈ 30–34 pages across 16 files, within the required 30–120 pages.
